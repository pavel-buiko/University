# University Coursework

Lab work and a course project collected under [2k2s](2k2s/), the second semester of the second year. Open the directory for the individual lab or project to find its source files and supporting materials.

| Folder | Contents |
| --- | --- |
| [Course](2k2s/Course/) | Oikia Vita property booking project with Oracle SQL scripts, a React frontend, a Node.js server, and an earlier WPF client. |
| [MatProg](2k2s/MatProg/) | Mathematical programming labs. |
| [Patterns](2k2s/Patterns/) | Design-pattern labs and lecture materials. |
| [Skuff](2k2s/Skuff/) | Labs and materials on special mathematical functions and methods. |
| [dataBase](2k2s/dataBase/) | Database labs and supporting materials. |

For Oikia Vita, start with the [course folder](2k2s/Course/) or the separate [booking-database](https://github.com/pavel-buiko/booking-database) repository.
